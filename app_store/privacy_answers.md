# App Privacy Answers

- Data collected: None for v1.
- Accounts: None.
- Payments: None.
- Advertising: None.
- Analytics: None.
- Location: Not collected.
- Contacts/photos/files: Not collected.
- Health data: Not collected.
- Local storage: Saved gene symbols are stored locally on the device.
- Live lookup: Gene symbol, species, and optional transcript ID are sent to the
  app backend only when the user performs live lookup.
- Third-party services: Live lookup depends on the app backend and Ensembl REST.
- Backend operational logs: Method, endpoint path without query string, status
  code, coarse error category, and duration only. No gene-search terms, mutation
  payloads, DNA/protein sequences, health data, contact data, or analytics
  profiles.
