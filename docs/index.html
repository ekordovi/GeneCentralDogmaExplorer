Educational biology app

Gene Central Dogma Explorer

Pick a gene, follow DNA to RNA to protein, compare simple mutations, and study the result without medical claims or database overload.

Support Privacy Policy GitHub

What It Does

The app opens with an offline HBB teaching example, then lets learners try HBB, BRCA1, TP53, or any Ensembl-supported gene.

Data Source

Live lookup uses the Gene Central Dogma Explorer API and Ensembl REST for gene, transcript, sequence, and protein data.

Important Limit

This is an educational tool, not medical advice, diagnosis, treatment guidance, or clinical variant interpretation.
